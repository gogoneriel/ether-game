# Akatsuki Flag — Fountain Decoration

## What
Add a red banner/flag near the town fountain with the text "Akatsuki" on it.

## Where
- Placed next to the fountain in Magnolia town square (fountain anchor).
- Visible to all players walking through the plaza.

## How
- Red flag sprite (simple pixel-art cloth on a pole).
- "Akatsuki" text rendered on the cloth.
- Static decoration — no interaction needed for v1.
